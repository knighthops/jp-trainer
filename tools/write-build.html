Build the handwriting lookup data

Reads every jōyō and jinmeiyō kanji from KANJIDIC2 (.dict/kanjidic2-en-3.6.2.json) and adds full-size hiragana and katakana, takes their strokes from KanjiVG (.dict/kanjivg-20260714.xml.gz, from github.com/KanjiVG/kanjivg/releases), and writes data/write.json for js/handwrite.js. Run tools/serve.ps1, then open this page.
